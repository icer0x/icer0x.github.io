Linux Keyboard Patcher

Saya sering nemu laptop yang di Windows keyboardnya normal. Pas booting Linux, keyboardnya cuma bisa dipake pas GRUB. Setelah GRUB dan mulai booting Linux sampai masuk ke Desktop, keyboardnya nggak bisa dipake. Nih fixnya. Pake aja. Gratis.

I often come across laptops whose keyboards work fine in Windows. When booting Linux, the keyboard only works in GRUB. After GRUB, as Linux boots and reaches the desktop, the keyboard stops working. Here's the fix. Give it a try. It's free.

Panduan singkat

Install dulu distro Linuxnya. Gunakan keyboard external, atau gunakan VIrtual Keyboard bawaan distromu. Kemudian, install paket yang sesuai dengan distromu, build sendiri dari source, atau jalankan saja binarynya dengan chmod +x. Aplikasi ini bisa dijalankan lewat terminal, atau via gui. Setelah aplikasi ini dijalankan pertama kali, aplikasi ini akan melakukan patching pada GRUBmu. Restart, dan di menu pilihan GRUB saat booting, coba aja GRUB entry mana yang bisa membuat keyboardmu jalan setelah selesai booting dan masuk ke Desktop. Kalau sudah ketemu entry yang sesuai, ingat entrynya, kemudian jalankan lagi aplikasinya. Pilih entry yang bisa membuat keyboardmu berfungsi, kemudian jadikan permanen.

Quick guide

First, install your Linux distro. Use an external keyboard, or your distro's built-in virtual keyboard. Then install the package for your distro, build it from source, or simply make the binary executable with chmod +x. You can run the application from the terminal or through a GUI. The first time you run it, the application will patch your GRUB configuration. Restart, then try the available GRUB entries to find one that lets your keyboard work after Linux boots to the desktop. Once you find the right entry, note it down and run the application again. Select the entry that makes your keyboard work, then make it permanent.
